## World generation

Maple Forest is added through TerraBlender. Its climate mapping controls where it can appear, while TerraBlender's global region-size setting controls the scale of modded biome regions.

If you want larger TerraBlender biome regions, change `overworld_region_size` in `config/terrablender.toml` from its default of `3` to `5`. This is a global TerraBlender setting, so it affects other mods that use TerraBlender too; it cannot be adjusted for this mod alone.
